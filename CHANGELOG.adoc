= Changelog

== 0.11.0

==== Enhancements

* Zulip 13 support
* `SendMessageApiRequest.executeWithResult()` returns a `SendMessageResult` with the message URL and Markdown link
* `MessageFlag.HIDE_LINK_PREVIEWS` added; unrecognized message flags now deserialize to `MessageFlag.UNKNOWN` instead of failing
* New endpoints: `createGoogleMeetVideoCall()`, `updateCustomProfileField()`, `deleteDataExport()`, `deactivateRealm()`, `uploadAvatar()`, `deleteAvatar()`
* `withDefaultPushNotifications()` on create channel, subscribe and update stream requests; `isDefaultPushNotifications()` on `Stream` and `StreamSubscription`
* `withCanCreateTopicGroup()` on create channel, subscribe and update stream requests
* `withExampleInput()`, `withReverseTemplate()` and `withAlternativeUrlTemplates()` on add and update linkifier requests
* `withUseForUserMatching()` on create custom profile field requests
* `withPopulateUrlEmbedData()` on render message requests
* `withSendMessagesToRemovedSubscribers()` on unsubscribe requests and `StreamUnsubscribeResult.isMessagesSentToRemovedSubscribers()`
* `DataExport.isExportFromPriorServer()`
* `SubscribeStreamsApiRequest.withSendNewSubscriptionMessages()` restored
* `EventType.HAS_GOOGLE_MEET_TOKEN` and `EventType.URL_EMBED_DATA` added

==== Bug fixes

* `GetMessagesApiRequest.withGravatar()` sent `gravatar` instead of `client_gravatar`, so the setting was ignored by the server

==== Breaking changes

* `RegisterE2EMobilePushDevice` updated for the redesigned Zulip API. `registerE2EMobilePushDevice()` now takes a device id, with the push key and token set via `withPushKey()` and `withToken()`
* `SendE2EMobilePushTestNotification.pushAccountId()` removed; replaced by `withDeviceId()`
* `CreateChannelApiRequest.withSendNewSubscriptionMessages()` removed; the parameter is not supported by the create channel endpoint. Use `SubscribeStreamsApiRequest.withSendNewSubscriptionMessages()` instead
* Upgraded to Jackson 3. Public APIs exposing Jackson types (e.g. `JsonUtils.getMapper()`, `GetEventsApiResponse.getEvents()`) now use the `tools.jackson` packages, and Jackson 2 (`com.fasterxml.jackson.core:jackson-databind`) is no longer a transitive dependency

==== Deprecations

* `MessageService.markStreamAsRead()` and `MessageService.markTopicAsRead()` are deprecated; use `updateMessageFlagsForNarrow()` instead

== 0.10.0

==== Enhancements

* Zulip 12 support
* https://github.com/jamesnetherton/zulip-java-client/issues/308[#308] - Add jwt_fetch_api_key support
* https://github.com/jamesnetherton/zulip-java-client/issues/445[#445] - Add ability to configure a trust store for self-signed Zulip server certificates

==== Breaking changes

* JDK 11 support has been dropped. The minimum supported JDK is now JDK 17
* `UserAttachment.getMessages()` removed; replaced by `UserAttachment.getMessageIds()` which returns `List<Long>`
* `UserAttachmentMessage` class removed
* `WebHomeView.RECENT_TOPICS` removed; replaced by `WebHomeView.RECENT`; new `WebHomeView.INBOX` added
* `DataExportType.STANDARD` removed; replaced by `DataExportType.FULL_WITH_CONSENT`; new `DataExportType.FULL_WITHOUT_CONSENT` added; `DataExportType.getId()` removed; replaced by `DataExportType.getValue()` returning a string
* `SubscribeStreamsApiRequest.withStreamPostPolicy()` removed; stream post policy can only be set via `updateStream()`
* `SubscribeStreamsApiRequest.withSendNewSubscriptionMessages()` removed
* `UpdateOwnUserSettingsApiRequest.withRealmNameInNotifications()` removed; use `withRealmNameInEmailNotifications()` instead
* `UpdateNotificationSettingsApiRequest.withRealmNameInNotifications()` removed
* `UpdateRealmNewUserDefaultSettingsApiRequest.withRealmNameInNotifications()` removed; use `withRealmNameInEmailNotifications()` instead
* `UpdateOwnUserSettingsApiRequest.DEFAULT_VIEW` parameter renamed from `default_view` to `web_home_view`
* `UpdateOwnUserSettingsApiRequest.ESCAPE_NAVIGATES_TO_DEFAULT_VIEW` parameter renamed from `escape_navigates_to_default_view` to `web_escape_navigates_to_home_view`
